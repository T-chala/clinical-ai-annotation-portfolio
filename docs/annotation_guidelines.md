# Annotation Guidelines

## Categories
- **SpecificDisease** — a specific named disease or disorder.
- **DiseaseClass** — a broader disease, disorder, condition, or disease-related class.
- **CompositeMention** — a combined mention representing multiple disease concepts as one annotated expression.
- **Modifier** — a disease-related modifier or qualifying expression annotated as such in the corpus schema.

## Working rules
1. Select the disease-related span itself.
2. Preserve the wording used in the source text.
3. Keep separate mentions separate.
4. Apply the corpus category consistently.
5. Review both obvious and less-obvious disease terminology for recall.
6. Treat disagreement analysis as a QA step.
